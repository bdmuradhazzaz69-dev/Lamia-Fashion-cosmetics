# Lamia Fashion House — প্রথম কার্যকর প্রোটোটাইপ

বাংলাদেশের বাজারের জন্য প্রিমিয়াম ফ্যাশন + ই-কমার্স UI প্রোটোটাইপ।

## চালানোর নিয়ম
1. ZIP ফাইলটি Extract করুন।
2. `index.html` ফাইল ব্রাউজারে খুলুন। অথবা GitHub repository-তে তিনটি ফাইল (`index.html`, `styles.css`, `app.js`) আপলোড করুন।
3. GitHub Pages চালু করলে স্ট্যাটিক ডেমো সাইট প্রকাশ করা যাবে।

## এখন যা কাজ করে
- রেসপনসিভ হোমপেজ, ক্যাটাগরি ও পণ্য গ্রিড
- পণ্য সার্চ, ক্যাটাগরি ফিল্টার ও দাম অনুযায়ী সাজানো
- পণ্যের বিবরণ, সাইজ/রং নির্বাচন
- কার্টে যোগ, পরিমাণ পরিবর্তন, পণ্য সরানো
- বাংলাদেশি টাকা (BDT) এবং ডেমো COD চেকআউট
- ডেমো অর্ডার ও নিউজলেটার তথ্য ব্রাউজারের `localStorage`-এ রাখা

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি **ফ্রন্টএন্ড প্রোটোটাইপ**, এখনো লাইভ ব্যবসায়িক স্টোর নয়। ডেমো অর্ডার দোকানদারের কাছে যায় না; অন্য ডিভাইসে দেখা যায় না; `localStorage`-এর ডেটা ব্রাউজার/ডিভাইস বদলালে হারিয়ে যেতে পারে। বাস্তব ব্যবহারের আগে নিরাপদ ব্যাকএন্ড, ডেটাবেস, অ্যাডমিন লগইন, সার্ভার-সাইড অর্ডার ভ্যালিডেশন, গোপনীয়তা নীতি, রিটার্ন/ডেলিভারি নীতি এবং প্রয়োজনে পেমেন্ট গেটওয়ে যুক্ত করতে হবে। কোনো পেমেন্ট কার্ড তথ্য এই ডেমোতে সংগ্রহ করা হয় না।

## ছবি ও ফন্ট
অনলাইন ছবি Unsplash থেকে এবং ওয়েব ফন্ট Google Fonts থেকে লোড হয়; তাই ছবি/ফন্টের জন্য ইন্টারনেট প্রয়োজন। ছবি বা লিংক পরিবর্তন করতে `app.js` ও `index.html` সম্পাদনা করুন।
